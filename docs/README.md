# `/docs` Verzeichnis

Zentrales Verzeichnis für die **Projektdokumentation** von nextjs-supabase-shadcn-starter.

Mögliche Inhalte, die hier strukturiert werden sollen:

- `architecture.md`: Detailentscheidungen zu TanStack/Next.js/Supabase.
- `security.md`: Sicherheitsrichtlinien, Action-Client Validierungen, Middleware RLS Hinweise.
- `deployment/`: Guides zum PM2 Setup, Environment-Generierung und Rollouts.
- `ai_workflow.md`: Wie Dokumente geparsed, OCR-Informationen mit `pdfjs-dist` extrahiert und Kandidaten für Lieferabgleiche ausgewählt werden.

## Hinweis:

Halte die Dokumentation präzise und update sie nach neuen Architektur-Refactorings (insbesondre bei Supabase Database Type Änderungen).
