# `/public` Verzeichnis

Statisches Verzeichnis von Next.js. Dateien hier sind direkt über die Root-URL (`/`) aufrufbar.

## Inhalte:
- `favicon.ico`, `robots.txt`, `manifest.json`.
- Bilder, Logos und SVG Assets.
- PDF-Vorlagen oder fixe Dokumente (wenn sie nicht via Datenbank / CDN ausgeliefert werden).
